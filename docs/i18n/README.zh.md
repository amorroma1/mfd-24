# MFD-24

*Multi-Function Display，24小时：驾驶舱的显示屏，以及时针一圈的一天。*

[English](../../README.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · [日本語](README.ja.md) · **中文**

**腕上的24小时仪表盘** — 为值班值更的人而造：飞行员、船员、无人机操作员、值班军官。

时针一天转一圈。你的当班在这一天上画成一段弧，随着值守逐渐消耗。可选的"失能告警"（dead-man）
监视器按固定间隔要求一个生命信号，无人应答则逐级升级为SOS，并留下一条袖口蹭不掉的 `MAN DOWN`
记录。表盘其余部分承载值班真正需要的遥测：带日期时组的Zulu时间、QNH、METAR缩写天气、最近的
机场或港口、剩余的日照时间。

## 要点

- **24小时表盘** — 正午在上、午夜在下（可翻转）。分针走自己的60分度环；秒是一个从刻度跳到刻度
  的游标——没有任何东西扫过表盘。
- **当班即弧** — 立即开始或预约开始，`DUTY: 02:29 REM` 倒计时，起止两端都有声音与震动提醒，
  熄屏也不例外。
- **警戒监视** — 每5/10/15分钟轻震手腕一次，30秒内以动作或触摸应答，否则以脉冲方式发出SOS:先连续
  呼叫30秒，随后每分钟一次双重SOS,共四次——每次先震一遍,再响两遍,音量可调(含静音)。始终无人
  应答：`MAN DOWN`、事发的Zulu时刻、弧上的一道刻痕、本班次日志(附本班次参数,新班次开始即清空)。可选记录未应答检查期间的脉搏,并与
  之前活动时的脉搏对照。离腕自动暂停——并且表盘会明说。
- **导出记录** — `EXPORT LOG` 把记录放到手表真正拥有的两条通道上:给手机相机的二维码,以及声音
  (Bell 202 AFSK,1200 Bd,8N1,接收端用 `minimodem --rx 1200`)。记录保留当前值班最近的 32 条事件,
  最多 30 天;下一次值班会清空它。声音始终携带完整记录;二维码只携带能装下的最新条目(无脉搏时全部
  32 条,有脉搏时约 14 条),并由 `END` 行明示:`END 14 OF 32`。只读,没有导入路径。
- **Nadir 日照带** — 当前位置日出到日落的时段，离线计算，极昼极夜均正确处理。
- **太阳标记与月亮标记** — 太阳与月亮以真实时角画在时圈上;月亮带着真实的月相。把标记对准天上的实物,表盘昼夜皆成罗盘。
- **5公里站点锁定** — 9,649个机场、港口、直升机场与发射场，内置194 KB索引。按类型区分剪影，
  军事设施以强调色标出。
- **诚实的常亮显示** — 同一张表盘，只是调暗。`AUTO` 在日落后隔行点亮像素——夜班期间绝不减淡。
- **原则上离线** — 只有天气和每日一次的 GitHub 版本检查触网。新版本只通知一次,并可在平台允许时直接从手表安装。没有配套App，没有账号，不向任何人上报数据。

## MFD-24-Mars

同一件仪表，向外一颗行星：一个可与 MFD-24 **并列安装**的独立表盘，走的是火星车的时间 —
`PERSEVERANCE` 或 `CURIOSITY`。时针每个火星日（24小时39分）转一圈，天底带描出火星的白昼和 −6°
的晨昏肩，小时环上的两条线标出通信窗口：内侧是与地球的直连链路（天体力学，离线计算），外侧是
MRO、Odyssey、TGO 中继卫星的过顶（JPL Horizons 星历）。任务 Sol 编号之后，地面站天线图标旁边，
是到地球的单程光行时间，实时更新。

## 安装

Wear OS 3.0+（API 30）。从[最新版本](https://github.com/amorroma1/mfd-24/releases/latest)
下载 `app-earth-release.apk`，用 ADB 安装：

```
adb install -r app-earth-release.apk
```

完整指南 —— 三条路线,从『只用一部手机』到从源码构建,附故障排查 —— 见 **[INSTALL.zh.md](INSTALL.zh.md)**。MFD-24 不上架 Google Play 是有意为之,指南中解释了原因。

## 它是怎样做出来的

由一个人设计、决定并佩戴，代码与 Claude（Anthropic）结对编写。凡能测量的常量都在手表上实测而非
推算，每条不变量都由测试钉住，没有在手腕上跑过的东西不会发布。`CLAUDE.md` 中的工作笔记是这次
协作的记录，有意保留在仓库里。
